This is a collection of open source UK and global environmental datasets. 

These datasets are free to use and organised by topic. This page will be updated periodically, and look out for data analysis projects using these datasets!

The following datasets are mainly tabular using file types .csv and .xlsx, making them perfect for beginner and intermediate data analysis projects. Useful tools include Microsoft Excel, Google Sheets, Python, R, Jupyter Notebook, Power BI and Tableau. 

<h2>Climate</h2>

World Bank - Climate Change Indicators
https://data.worldbank.org/topic/climate-change 

NOAA  - Global Historical Climatology Network (GHCN)
https://www.ncei.noaa.gov/products/land-based-station/global-historical-climatology-network-daily 

NOAA - Climate Data Online (CDO)
https://www.ncei.noaa.gov/cdo-web/

https://nrfa.ceh.ac.uk/data/about-data/rainfall-data/catchment-rainfall

<h1>Other data types</h1>
